# RPC Performance Testing Suite

A clean and focused performance testing suite for RPC nodes using k6 load testing.

## Overview

This suite provides two main performance tests:

1. **Debug Trace Performance Test** - Tests `debug_traceBlockByNumber` RPC calls
2. **Eth Call Performance Test** - Tests `eth_call` RPC calls with transaction replay

## Key Features

- **Transaction Replay**: Records encoded calls during setup and replays them for accurate eth_call testing
- **HTTP Duration Tracking**: Detailed request/response timing metrics
- **Clean Architecture**: Removed unnecessary complexity and files
- **Automated Setup**: Deploys contracts and generates test data automatically

## Files

- `setupForPerfTests.ts` - Main setup script that deploys contracts and runs tests
- `k6_debug_trace_perf.js` - Debug trace performance test
- `k6_eth_call_perf.js` - Eth call performance test with replay functionality
- `k6.env` - Environment variables (generated by setup)
- `perf_test_blocks.json` - Test data with transaction records (generated by setup)
- `README.md` - This file

## Quick Start

### Prerequisites

1. **Install k6**:
   ```bash
   # macOS
   brew install k6
   
   # Linux
   sudo gpg -k
   sudo gpg --no-default-keyring --keyring /usr/share/keyrings/k6-archive-keyring.gpg --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys C5AD17C747E3415A3642D57D77C6C491D6AC1D69
   echo "deb [signed-by=/usr/share/keyrings/k6-archive-keyring.gpg] https://dl.k6.io/deb stable main" | sudo tee /etc/apt/sources.list.d/k6.list
   sudo apt-get update
   sudo apt-get install k6
   ```

2. **Ensure your RPC node is running** at `http://127.0.0.1:8545`

### Running Tests

```bash
# Run complete test (setup + both tests)
npx tsx setupForPerfTests.ts
```

This will:
1. Deploy the disperseEther contract
2. Send 50 transactions and record block numbers
3. **Record encoded calls** for each transaction
4. Run debug_trace performance test
5. Run eth_call performance test using recorded transaction data

## Test Details

### Debug Trace Performance Test

Tests the `debug_traceBlockByNumber` RPC endpoint by:
- Replaying historical blocks with disperseEther transactions
- Measuring trace generation time
- Recording gas usage and transaction counts

**Metrics collected:**
- Trace duration (95th percentile < 35s)
- Success rate (> 95%)
- Error rate (< 5%)
- Block transaction count
- Block gas usage

### Eth Call Performance Test (Replay Mode)

Tests the `eth_call` RPC endpoint by:
- **Replaying recorded transactions** from the setup phase
- Using the exact encoded calls that were executed
- Testing against the same block numbers where transactions occurred
- Measuring call response times

**Key Features:**
- **Transaction Replay**: Uses recorded `encodedCall`, `to`, and `value` data
- **HTTP Duration Tracking**: Detailed request/response timing
- **Accurate Testing**: Tests the exact same calls that were executed

**Metrics collected:**
- Call duration (95th percentile < 5s)
- HTTP request duration
- Success rate (> 95%)
- Error rate (< 5%)
- Gas usage per call
- Block number distribution

## Configuration

The setup script generates a `k6.env` file with:

| Variable | Description |
|----------|-------------|
| `K6_BLOCKS` | JSON array of block numbers with transactions |
| `K6_FIRST_BLOCK` | First block number with transactions |
| `K6_LAST_BLOCK` | Last block number with transactions |
| `K6_CONTRACT_ADDRESS` | Deployed disperseEther contract address |
| `K6_ADMIN_ADDRESS` | Admin address that deployed the contract |
| `K6_RPC_URL` | RPC endpoint URL |

The eth_call test uses this data to replay the exact same calls that were executed during setup.

## Troubleshooting

### Common Issues

1. **k6 not found**: Install k6 using the instructions above
2. **RPC connection failed**: Check that your RPC node is running at `http://127.0.0.1:8545`
3. **Permission denied**: Make sure you have write permissions in the directory

### Debug Mode

```bash
# Enable k6 debug output
K6_DEBUG=true k6 run k6_eth_call_perf.js
```

## Architecture

```
setupForPerfTests.ts
├── Deploy disperseEther contract
├── Send 50 transactions
├── Record block numbers and encoded calls
├── Generate k6.env
└── Run both k6 tests

k6_debug_trace_perf.js
└── Test debug_traceBlockByNumber on recorded blocks

k6_eth_call_perf.js
├── Load transaction data from perf_test_blocks.json
├── Replay encoded calls on same blocks
└── Track HTTP request/response durations
```

This clean architecture focuses on accurate performance testing with transaction replay for realistic eth_call testing.
